1. Pengenalan Aplikasi

Stechoq RFID Suite adalah aplikasi Android untuk membaca tag RFID UHF dan barcode menggunakan handheld gudang, lalu mengirim hasilnya secara otomatis ke sistem Warehouse Management (WMS). Satu aplikasi yang sama dapat dipasang di dua merek perangkat berbeda:

  • Chainway C72 — handheld dengan reader UHF bawaan
  • Zebra MC33 / MC3300x — handheld dengan reader UHF bawaan

Fitur utama yang tersedia:

  • Scan RFID banyak tag sekaligus, cukup tahan tombol trigger fisik
  • Indikator Kualitas sinyal per tag (Kuat / Sedang / Lemah) — menggantikan angka RSSI mentah yang sulit dibaca operator
  • Mode Barcode — beralih dari RFID ke pemindai barcode 1D/2D dengan satu tombol di Pengaturan
  • Dua alur pengiriman data: WO dan Register, dengan format data yang sama ke server
  • Tetap bisa scan walau aplikasi di latar belakang, dengan bulatan status mengambang di layar
  • Backup otomatis ke file CSV di perangkat, sebagai jaring pengaman saat WiFi gudang bermasalah
  • Update aplikasi otomatis lewat internet, tanpa kabel data dan tanpa laptop
  • Bahasa Indonesia dan Inggris, bisa diganti kapan saja
Untuk siapa dokumen ini? Bab 1–9 dan 12 ditulis untuk operator lapangan sehari-hari. Bab 10 (Pengaturan) lebih rinci dan biasanya hanya disentuh oleh admin/IT saat konfigurasi awal sebuah handheld.

2. Memulai: Instalasi & Pemilihan Perangkat

Aplikasi dipasang sekali oleh admin/IT (lewat file APK atau update otomatis). Setelah dipasang dan dibuka untuk pertama kali, aplikasi akan menanyakan jenis perangkat yang digunakan:

1 Pilih Chainway C72 jika handheld yang dipakai buatan Chainway.
2 Pilih Zebra jika handheld yang dipakai adalah MC33 atau MC3300x.
Penting: Pilihan ini hanya ditanyakan sekali dan disimpan khusus untuk perangkat tersebut — terpisah dari Pengaturan lain, sehingga tombol Reset di Pengaturan tidak akan pernah mengubahnya secara tidak sengaja. Untuk mengganti pilihan ini, aplikasi perlu dipasang ulang atau datanya dihapus lewat menu Setelan Android → Aplikasi.

Setelah jenis perangkat dipilih, aplikasi langsung masuk ke Layar Utama (Scan) dan siap digunakan. Semua pengaturan lain (URL server, mode WO/Register, dsb.) diisi lewat menu Pengaturan — lihat Bab 10.

3. Layar Utama (Scan)

Ini adalah layar yang paling sering dipakai operator sehari-hari.

Layar Scan dalam keadaan kosong, siap memulai

Bagian-bagian layar

  • Kartu ringkasan — menampilkan Total Terdeteksi (jumlah total pembacaan) dan Total Unik (jumlah tag berbeda), serta waktu scan terakhir.
  • Mulai Scan / Stop Scan — tekan tombol di layar, atau tahan tombol trigger fisik di handheld. Melepas trigger sama seperti menekan Stop.
  • Scan Baru vs Lanjutkan — begitu ada tag terbaca, tombol berubah jadi dua pilihan:
    • Scan Baru — menghapus semua hasil sebelumnya dan mulai sesi baru dari nol
    • Lanjutkan — tetap menyimpan tag yang sudah ada dan melanjutkan scan (berguna untuk menyisir area luas tanpa kehilangan hasil sebelumnya)
  • Status pengiriman — setelah scan berhenti, daftar tag otomatis dikirim ke server. Muncul status Mengirim → Terkirim (n tag), atau tombol Coba Lagi jika gagal.

Daftar tag

Setiap baris pada daftar tag menampilkan:

  • Kode EPC tag (kode unik tag RFID)
  • R: jumlah berapa kali tag ini terbaca dalam sesi berjalan
  • Kualitas — lihat penjelasan lengkap di Bab 4
  • Label BARU atau LAMA — menandai apakah tag ini baru pertama kali terbaca pada sesi ini, atau sudah ada sebelumnya
  • Ikon salin — ketuk untuk menyalin kode EPC tag tersebut
Baris tag: kode EPC, jumlah baca (R), dan label Kualitas

Di atas daftar tag terdapat kotak Cari EPC untuk menyaring tag berdasarkan sebagian kode EPC, dan ikon urutkan (≡) untuk mengubah urutan: terbaru, EPC (A–Z), jumlah baca terbanyak, atau Kualitas terbaik.

4. Kualitas Sinyal (Quality)

Sebelumnya, setiap baris tag menampilkan angka RSSI mentah (misalnya "-58 dBm"), nomor antena, dan waktu terakhir terbaca. Operator di lapangan sulit memaknai angka-angka ini, sehingga sekarang digantikan dengan satu label sederhana: Kualitas.

5. Mode Barcode

Selain RFID, aplikasi ini juga bisa dipakai untuk memindai barcode 1D/2D menggunakan pemindai bawaan handheld. Mode ini diaktifkan dari menu Pengaturan → Mode Scan, dan secara default aplikasi berada dalam Mode RFID.

Mode Scan — tombol Barcode dipilih (berwarna ungu)

Saat Mode Barcode aktif, tampilan Layar Scan berubah warna menjadi aksen ungu agar operator langsung tahu mode mana yang sedang berjalan tanpa perlu membaca teks.

Cara pakai

1 Buka Pengaturan, di bagian paling atas pilih Mode Scan → Barcode, lalu tekan Simpan.
2 Kembali ke Layar Scan — tampilan akan berubah menjadi tema ungu dengan ikon barcode.
3 Arahkan handheld ke barcode, lalu tahan tombol trigger seperti biasa hingga barcode terbaca.
4 Setiap barcode yang berhasil terbaca langsung dikirim otomatis ke server, satu per satu — tidak perlu menekan Stop terlebih dahulu.
Menunggu scan pertama
Hasil scan dengan status kirim

Setiap baris hasil pada Mode Barcode menampilkan kode yang terbaca, waktu scan, dan status pengiriman: Mengirim…, Terkirim (hijau), atau Gagal (merah).

Perbedaan penting dengan Mode RFID:
  • Pengaturan Power (kekuatan pancar RF) otomatis disembunyikan saat Mode Barcode aktif, karena tidak relevan untuk pemindaian barcode.
  • Backup CSV lokal (Bab 8) tidak mencakup hasil Mode Barcode — backup itu khusus untuk sesi RFID, karena setiap barcode sudah langsung terkirim satu per satu, bukan dikumpulkan dulu.

6. Mode Pengiriman: WO vs Register

Terlepas dari Mode Scan (RFID/Barcode) di atas, ada satu pengaturan lagi yang menentukan ke alur bisnis mana hasil scan dikirim: WO atau Register. Diatur dari Pengaturan → Mode.

Bagian Mode Scan (atas) dan Mode WO/Register (bawah) di Pengaturan

Kedua mode mengirim data dengan format yang sama persis ke server yang sama — server membedakannya lewat satu penanda di data yang dikirim, sehingga operator tidak perlu memikirkan perbedaan teknisnya.

Khusus Mode Register muncul satu centang tambahan: "Hasil scan langsung dikirim ke stok saat ini". Jika dicentang, hasil scan tersebut juga langsung memperbarui stok saat itu juga. Kotak centang ini tidak muncul sama sekali di Mode WO.

7. Scan Latar Belakang & Bulatan Mengambang

Fitur ini mati secara default. Jika diaktifkan lewat Pengaturan → Scan Latar Belakang, dua hal berubah:

1 Tombol trigger fisik tetap berfungsi walau aplikasi tidak sedang dibuka di layar — misalnya sambil membuka Chrome atau aplikasi WMS lain. Jika fitur ini mati, trigger hanya berfungsi saat aplikasi sedang tampil di layar.
2 Muncul bulatan status mengambang di atas aplikasi lain. Bulatan ini bisa digeser ke mana saja, dan diketuk untuk langsung kembali ke aplikasi.

Warna bulatan menunjukkan status tanpa perlu membaca teks:

Mengaktifkan fitur ini akan meminta izin Android "Tampil di atas aplikasi lain" — cukup disetujui satu kali per perangkat. Karena fitur ini menjalankan layanan latar belakang, akan selalu muncul notifikasi kecil "Background scanning active" di status bar selama fitur ini aktif — ini adalah ketentuan standar Android, bukan bug.

8. Backup CSV Lokal

Fitur ini menyala secara default, diatur lewat Pengaturan → Backup Lokal. Setiap kali sesi scan RFID berhenti — berhasil terkirim maupun tidak — seluruh daftar tag pada sesi tersebut otomatis disimpan ke file CSV di penyimpanan perangkat. Fitur ini adalah jaring pengaman apabila koneksi WiFi gudang sedang tidak stabil.

File tersimpan otomatis di folder:

Android/data/com.example.chainwayrfidbridge/files/rfid_stc/

satu file per sesi scan, dengan nama scan_YYYYMMDD_HHMMSS.csv, berisi kolom: epc, first_seen, last_seen, read_count, antenna, rssi, is_new.

Backup ini hanya berlaku untuk sesi Mode RFID. Hasil Mode Barcode (Bab 5) tidak dibackup ke CSV karena setiap kode sudah langsung dikirim satu per satu ke server.

9. Update Aplikasi Otomatis

Aplikasi secara otomatis memeriksa versi terbaru setiap kali dibuka, dan setiap kembali ke layar depan (paling cepat setiap 5 menit sekali). Jika tersedia versi baru, muncul kartu notifikasi di Layar Scan:

Kartu "Update tersedia" muncul di bagian atas Layar Scan
1 Tekan Update Sekarang untuk mengunduh versi terbaru.
2 Setelah selesai diunduh, tekan Pasang — ini akan membuka pemasang aplikasi bawaan Android.
3 Khusus pemasangan pertama kali di sebuah perangkat, Android mungkin menampilkan layar izin "Izinkan pemasangan dari aplikasi ini" — cukup disetujui satu kali, bukan setiap update.

Tidak perlu laptop, kabel data, atau transfer APK manual — semua dilakukan langsung dari handheld lewat internet.

10. Panduan Lengkap Pengaturan

Bab ini menjelaskan setiap bagian di menu Pengaturan, dari atas ke bawah. Bagian ini biasanya hanya perlu disentuh sekali oleh admin/IT saat konfigurasi awal sebuah handheld.

10.1 Mode Scan & Mode

  • Mode Scan — RFID / Barcode, lihat Bab 5
  • Mode — WO / Register, lihat Bab 6

10.2 Konfigurasi API

  • Base URL — alamat server WMS tujuan
  • Endpoint — jalur API tujuan, biasanya tidak perlu diubah
  • Reader ID — hanya-baca, dibuat otomatis dari perangkat sehingga setiap handheld punya ID unik tanpa perlu diatur manual
  • Antenna — nomor antena yang dipakai

10.3 Test Connection & Register Configuration

  • Test Connection — mengecek apakah alamat server bisa dihubungi
  • Register Configuration — RR Type, Maker Name, Initial Year, Factory Code (selalu dikirim ke server terlepas dari Mode WO/Register yang dipilih)

10.4 Power

Mengatur kekuatan pancar RF reader. Rentang nilai mengikuti perangkat aslinya: Chainway 1–30 dBm, Zebra 0–300 (sama seperti aplikasi resmi 123RFID milik Zebra). Bagian ini otomatis disembunyikan saat Mode Barcode aktif.

10.5 Suara

Bunyi setiap kali tag/barcode berhasil terbaca, bisa dimatikan, lengkap dengan pengatur volume.

10.6 Backup Lokal, Scan Latar Belakang & Bahasa

Lihat Bab 7, Bab 8, dan Bab 11 untuk penjelasan masing-masing.

10.7 Reset & Simpan

  • Reset — mengembalikan semua pengaturan di atas ke nilai bawaan (tidak pernah mengubah pilihan jenis perangkat atau bahasa)
  • Simpan — memvalidasi lalu menyimpan seluruh perubahan; versi aplikasi yang terpasang ditampilkan tepat di bawah tombol ini

11. Bahasa Aplikasi

Tersedia dalam Bahasa Indonesia dan Inggris, bisa diganti kapan saja lewat menu Pengaturan, dan berlaku instan ke seluruh layar — termasuk notifikasi dan pesan validasi. Secara bawaan, aplikasi terpasang dalam Bahasa Inggris hingga diganti manual.

12. Pemecahan Masalah (Troubleshooting)

GejalaPenjelasan & solusi
Muncul pesan error terkait charging saat scan RFID (khusus Zebra) Sebagian unit Zebra menolak memulai scan RFID saat merasa sedang di-charge, termasuk saat tersambung ke dock USB/adb. Ini bukan bug — lepas dari charger lalu coba lagi.
Laser barcode ikut menyala saat scan RFID (khusus Zebra) Mesin barcode DataWedge milik Zebra kadang mengambil alih tombol trigger saat aplikasi lain yang punya profil DataWedge sendiri (mis. browser) tampil di depan. Aplikasi ini otomatis menonaktifkan DataWedge setiap kali Mode RFID aktif. Jika terus berulang di satu unit tertentu, laporkan ke tim IT sebagai kemungkinan masalah profil DataWedge di unit tersebut.
Trigger memicu pemindai barcode (lampu menyala, berhasil membaca) tapi hasilnya tidak pernah muncul di aplikasi (Mode Barcode, khusus Zebra) Ini adalah masalah konfigurasi profil DataWedge di sistem — hasil scan terkirim ke profil lain, bukan ke aplikasi ini. Laporkan ke tim IT; solusinya bersifat teknis di sisi sistem, bukan sesuatu yang bisa diperbaiki operator sendiri di lapangan.
Update tidak mau terpasang Bisa terjadi jika perangkat pernah dipasangi APK versi uji coba/manual oleh tim IT. Hubungi tim IT untuk memasang ulang aplikasi ke versi resmi.
Unduhan update terhenti/timeout Aplikasi mengunduh file update (beberapa MB) lewat jaringan handheld; pada WiFi gudang yang lambat, percobaan pertama kadang gagal. Tekan Update Sekarang sekali lagi untuk mencoba ulang.
